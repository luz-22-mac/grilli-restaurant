### Pré-requisitos

Antes de começar, certifique-se de ter instalado:

* [Git](https://git-scm.com/downloads "Download Git") no seu sistema operacional.

### Executar localmente

Para rodar o **Grilli** localmente, execute este comando no seu terminal:

Linux e macOS:

```bash
sudo git clone https://github.com/pycacau/grilli-restaurant.git
```

Windows:

```bash
git clone https://github.com/pycacau/grilli-restaurant.git
```
